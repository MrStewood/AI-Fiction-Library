# Agent instruction sources (studio 0.1.0)

These files are the canonical instruction packs for the board hires.

Each role provides:
- `*_AGENTS.md` — operating instructions (entry file)
- `*_SOUL.md` — posture / values
- `*_HEARTBEAT.md` — wake behavior
- `*_TOOLS.md` — tools and paths

Shared injection: `SHARED_CONSTITUTION.md` (also mirrored in `../policies/CONSTITUTION.md`).
