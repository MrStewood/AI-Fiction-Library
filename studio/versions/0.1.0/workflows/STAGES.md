# Workflow stages (v0.1.0)

Only the Managing Editor may advance stages.

0. Intake
1. Creative Brief
2. Premise
3. Story Bible + Ending
4. Beat Sheet
5. Scene Outline
6. Drafting (sequential units)
7. Full-draft developmental review
8. Developmental / continuity revision
9. Line edit
10. Final audit + release

Hard rules:

- No full manuscript draft before premise, ending, beats, and scene outline pass review
- Reviewers diagnose; revision agents revise
- No self-approval
- Bounded revision loops
- One drafting unit at a time
